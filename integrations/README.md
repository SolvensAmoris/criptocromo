# Integraciones externas

Las integraciones de IA aún no están conectadas. Esta carpeta reserva el límite arquitectónico para adaptadores de proveedores y herramientas.

Contrato conceptual: PROPOSE, STRUCTURE, CRITIQUE, REQUEST_SIMULATION y REVIEW_RESULTS.

Ningún proveedor, incluido Meta AI, será obligatorio para ejecutar Criptocromo. No incluir claves ni secretos en el repositorio.
